# YouTube Downloader

맥에서 유튜브 영상을 **MP4 · MP3 · WAV** 로 저장하는 앱입니다. 음악 작업(로직 프로)용으로 만들었습니다.

## 받기

오른쪽 **Releases** 에서 최신 `YouTube-Downloader-*.zip` 을 받아 압축을 풀고,
`YouTube Downloader.app` 을 응용 프로그램 폴더로 옮기면 끝입니다.

**설치할 건 아무것도 없습니다.** 터미널도, 파이썬도, Homebrew 도 필요 없습니다.

## 처음 한 번만

다른 사람이 만든 앱이라 macOS 가 처음에 한 번 막습니다. 개발자 등록($99/년)이 안 된 앱이라 그렇습니다.

1. 앱을 더블클릭 → "열 수 없습니다" 창이 뜨면 닫기
2. **시스템 설정 → 개인정보 보호 및 보안** 열기
3. 아래로 내리면 `"YouTube Downloader"이(가) 차단되었습니다` 옆에 **[그래도 열기]** → 한 번 더 **[열기]**

이후로는 그냥 더블클릭으로 열립니다.

## 쓰는 법

1. 유튜브 링크를 붙여넣습니다 (여러 개면 한 줄에 하나씩, 재생목록 주소도 됩니다)
2. 저장할 형식을 체크합니다 — MP4(영상) · MP3(음원) · WAV(무손실, 로직용)
3. **다운로드**

받은 파일은 기본적으로 `음악 > YouTube Downloads` 폴더에 저장됩니다. 위치는 바꿀 수 있습니다.

## 알아두면 좋은 것

- 앱이 **스스로 최신 상태를 유지합니다.** 유튜브가 다운로드를 막으면 보통 하루 이틀 안에 풀리는데, 앱이 알아서 받아옵니다
- "봇이 아님을 확인" 오류가 나면 **고급 설정 → 브라우저 로그인 정보 사용** 을 Safari 나 Chrome 으로 바꿔 보세요
- Apple Silicon · Intel 맥 모두 지원 (macOS 12 이상)

## 안에 든 것

[yt-dlp](https://github.com/yt-dlp/yt-dlp) · [FFmpeg](https://ffmpeg.org) · [QuickJS](https://github.com/quickjs-ng/quickjs) 를 앱 안에 포함하고 있습니다.
